# Capability matrix — NetworkManager3 1.2.0-rc2

Generated by `scripts/capability_matrix.py` from `backend/domain/adapters.py` (the registry served by `/api/v1/capability-matrix`), `/api/v1/system/features` and `evidence/certification/`.

**Hardware certification: none.** Every operation below is `UNCERTIFIED` for hardware. The emulated columns are SOFTWARE PASS ONLY (strict protocol emulators); an operation becomes executable on a real device only after it is certified on that model/firmware train in a lab, independently approved, and the owner unlocks writes (`INM_DEVICE_WRITE_LOCK=false` + `INM_ALLOW_CONFIG_CHANGES=true`). Hardware writes stayed locked for this whole campaign.

**Device-originated log reads:** Aruba Instant now implements read-only `show log system/security/user` and CX implements REST `/logs/audit` and `/logs/event`. Normalization limits output to 100 entries, redacts credential-like fields, and requires an authenticated operator, auditor, or administrator. These methods passed software emulator tests only; the physical-device REST/CLI response shapes remain **UNCERTIFIED**. The `Device 360 → Operations` viewer calls `GET /api/v1/devices/{device_id}/device-logs`. This is separate from the platform's hash-chained audit trail.
